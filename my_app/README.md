# Flutter Login UI 🔐

A clean and modern **Login Screen UI built with Flutter**.  
This project focuses on creating a simple, responsive, and visually appealing authentication interface.

## 📱 Preview

<p align="center">
  <img src="assets/login-screen.png" alt="Flutter Login Screen" width="300"/>
</p>

## ✨ Features

- 🔐 Modern login interface
- 📧 Email input field
- 🔑 Password input field
- 👁️ Password visibility protection
- 🔗 Forgot Password option
- 🔓 Login button
- 👤 Create New Account option
- 🌐 Social login UI
  - Google
  - Facebook
  - Apple
- 🎨 Custom colors and borders
- 📱 Responsive Flutter UI

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design
- Font Awesome Flutter
